# Конструктор трасс хуперса

Локальный редактор трассы: план сверху и объёмный вид в одной сцене Three.js. Предупреждения по классам H1–H3 не блокируют правку.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173`). Пока этот порт занят, второй `npm run dev` не запускайте.

`npm test` — проверки чертежа и правил. `npm run build` — сборка.

## Как собирать трассу

Старт: ринг 30×20 м, класс H1, одна зона управления в центре.

- Кнопка снаряда или **Добавить номер** включает постановку: следующий щелчок по свободному месту ринга ставит предмет. Повторный щелчок по кнопке или Escape выключает её. Перенос кнопки на ринг ставит один предмет сразу.
- Сетка 1 м, привязка 0,5 м. Жёлтая ручка поворачивает снаряд с шагом 15°.
- Номер — отдельный знак 1–25, не привязан к снаряду. Один снаряд можно отметить несколькими номерами.
- Конус: диаметр 20–30 см. В комплекте РКФ его нет, в счёте предметов он есть.
- Зона управления: круг или квадрат 2 м. В центре стоит фигурка хендлера, её можно перетащить вместе с зоной.
- Виды: **Сверху** и **Объём**.
- Delete удаляет выбранное, Escape выключает постановку.

Черновик пишется в `localStorage` (`hoopers.course.draft`). **Сохранить** скачивает `trassa-hupers.json`, **Открыть** читает такой файл, **Новый** сбрасывает чертёж.

## Классы

| | H1 | H2 | H3 |
|---|---|---|---|
| Снарядов | 10–15 | 15–20 | 20–25 |
| Между номерами | 4–8 м | 5–10 м | 6–12 м |
| От зоны до дальнего | ≤12 м | ≤18 м | ≤30 м |

Ринг не меньше 400 м², короткая сторона не меньше 20 м. Арок — не меньше половины снарядов. Старт и финиш — арка или туннель рядом с первым и последним номером. Комплект: 12 арок, 6 бочек, 3 ворот, 2 туннеля. Конус в комплект не входит.

Координаты плана: `x` — длина, `y` — ширина. В сцене это `(x, 0, y)`.
