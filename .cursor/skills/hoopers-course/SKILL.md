# Конструктор трасс хуперса

## Карта

- `src/model/course.ts` — чертёж, `snap`, `parseCourse`, версия 1. Снаряды и знаки — разные списки. Линии хода нет.
- `src/rules/equipment.ts` — размеры, лимиты комплекта и классов
- `src/rules/classChecks.ts` — предупреждения, без блокировки правки
- `src/scene/viewport.ts` — одна сцена, ортокамера сверху и перспектива
- `src/scene/courseView.ts`, `src/scene/meshes.ts` — ринг, сетка, снаряды
- `src/editor/interaction.ts` — перетаскивание стоящих снарядов, знаков, фигурки и поворот. Кнопка включает постановку, щелчок по рингу ставит; перенос с кнопки тоже ставит.
- `src/ui/panel.ts` — русская панель
- `src/persist/storage.ts` — черновик `hoopers.course.draft` и файл `trassa-hupers.json`

План `(x, y)` = мир `(x, 0, y)`. Верхняя камера: `up` = `+Z`, `left`/`right` переставлены.

## Правка

1. Размеры и пороги меняй только в `equipment.ts`.
2. Новое предупреждение: код в `checkCourse` и кейс в `classChecks.test.ts`.
3. Поле чертежа: тип в `CourseDocument`, строгая проверка в `parseCourse`, сцена и панель.
4. Снаряд рисуй процедурно в `meshes.ts`, не подключай внешние модели.

Предупреждения не должны отключать перетаскивание. Шаг поворота 15°, привязка 0,5 м.

## Проверка

- Логика: `npm test`
- Тип: `npx tsc --noEmit`
- Интерфейс, камера, перетаскивание: оба вида в браузере, пустая трасса и трасса с номерами
- Не запускай второй `npm run dev`, если занят порт 5173
